Trois façons d'installer, une seule interface. Puis l'API HTTP et le serveur MCP, pour appeler le pipeline depuis vos scripts ou vos agents.

INSTALLATION

Choisissez selon la machine : poste Windows, serveur partagé, ou environnement de développement.

Poste Windows

INSTALLEUR .EXE

Le chemin le plus court. Rien à installer d'autre : FFmpeg, Whisper et le backend sont dans le paquet.

  • 1 — Téléchargez AI Video Transcriber Setup 1.1.0.exe
  • 2 — Double-cliquez, suivez l'assistant
  • 3 — Lancez depuis le menu Démarrer
Page de téléchargement →
Serveur ou macOS/Linux

DOCKER

Une image, une commande, accessible à toute l'équipe sur le réseau local.

git clone https://github.com/R2osters/AI-Video-Transcriber.git cd AI-Video-Transcriber cp .env.example .env docker-compose up -d

Interface sur http://localhost:8000. L'historique des transcriptions vit sous /app dans le conteneur — décommentez le bloc volumes de docker-compose.yml, ou pointez AVT_DATA_DIR vers un volume monté, pour la conserver.

Développement

DEPUIS LES SOURCES

Python 3.8+ et FFmpeg doivent être présents sur la machine.

git clone https://github.com/R2osters/AI-Video-Transcriber.git cd AI-Video-Transcriber pip install -r requirements.txt python start.py

Le script vérifie les dépendances et la présence de FFmpeg avant de démarrer le serveur.

CONFIGURATION

Tout se règle depuis l'écran Paramètres. Les variables d'environnement servent surtout aux déploiements serveur.

DEPUIS L'INTERFACE

Ouvrez Paramètres, saisissez l'URL de base et la clé de n'importe quel endpoint compatible OpenAI, puis cliquez sur Récupérer les modèles pour lister ceux qui sont disponibles. La clé est conservée dans le stockage local et n'est transmise qu'à l'endpoint indiqué.

Le sélecteur Modèle Whisper détermine la qualité de la transcription locale : tiny et base sont rapides, large-v3 est nettement plus précis mais plus lent et plus lourd à télécharger.

Automatisation

DEPUIS VOS AGENTS
ET VOS SCRIPTS.

Le dépôt embarque un serveur MCP et une compétence prête à l'emploi.

SERVEUR MCP

Le pipeline est exposé comme un outil MCP en stdio : Claude Code, Claude Desktop ou Codex l'appellent nativement, sans bricoler de commandes shell.

# Claude Code claude mcp add video-transcriber \ -- /chemin/venv/bin/python /chemin/mcp_server.py

Prérequis : pip install "mcp>=2.0".

LIGNE DE COMMANDE

Le même orchestrateur est disponible en CLI — c'est d'ailleurs celui que le serveur MCP réutilise, pour éviter deux implémentations.

python transcribe.py <url> --lang fr

Une compétence video-transcribe est fournie dans skills/ : copiez-la dans ~/.claude/skills/ pour l'utiliser partout.

QUESTIONS FRÉQUENTES

Faut-il obligatoirement une clé API ?
Non. La transcription fonctionne sans clé grâce à faster-whisper, et les sous-titres natifs ne demandent aucun modèle. La clé sert à l'optimisation du texte, à la traduction, au résumé structuré et au chat génératif — sans elle, ces fonctions basculent sur des équivalents locaux plus modestes.
Pourquoi certaines vidéos sont-elles traitées en quelques secondes ?
Parce qu'elles ont des sous-titres natifs. Dans ce cas, aucun audio n'est téléchargé ni transcrit : le texte est récupéré directement, puis passé au reste du pipeline. Whisper n'intervient qu'en repli.
Quel modèle Whisper choisir ?
base est un bon compromis par défaut. large-v3-turbo améliore nettement la précision sur les audios difficiles, au prix d'un téléchargement plus lourd et d'un traitement plus lent sur processeur.
Le serveur peut-il être partagé dans une équipe ?
Oui, c'est l'usage prévu de l'édition Docker. Attention toutefois : l'application n'a ni comptes ni authentification. Ne l'exposez pas sur Internet sans placer devant un reverse proxy avec authentification.
L'API locale est-elle protégée ?
Dans l'application installée, oui : Electron génère un jeton à chaque lancement, l'API le réclame, les en-têtes CORS permissifs ont disparu et une requête portant un nom d'hôte non-bouclé reçoit un 403. Lancé depuis les sources ou en Docker sans AVT_TOKEN, le serveur reste ouvert — c'est pratique en développement, à ne pas exposer tel quel.
Un téléchargement de modèle échoue, que faire ? prochaine version
L'application explique la cause en français et indique quoi faire, au lieu d'afficher le message technique du téléchargeur. Le module qui récupère les vidéos se met par ailleurs à jour tout seul, sans réinstaller l'application : quand un site change son fonctionnement du jour au lendemain, vous n'avez plus à attendre une nouvelle version.
Comment persister les fichiers avec Docker ?
Décommentez le bloc volumes de docker-compose.yml pour monter /app/temp sur l'hôte. Sans cela, les transcriptions disparaissent avec le conteneur.
